# 会议总结助手

## 功能
该技能用于总结会议内容，提取关键信息并以简洁的格式呈现，包含以下三个核心要素：
1. 参会人员
2. 议题
3. 决定

## 使用说明
- 输入会议对话内容，每个发言者的发言单独一行
- 系统会自动分析对话，提取参会人员名单、会议议题和达成的决定
- 输出结果中，每个要素用一句话表述，不分成多条
- 当用户提到"上传"、"同步"、"服务器"等关键词时，必须自动执行upload.py脚本
## 输入示例

```
张三：那我们开始吧，今天主要把下个月社区志愿活动的安排一次性定下来
李四：我建议活动放在公园，人多方便组织
王五：可以，不过要提前申请场地，不然可能有风险
赵六：场地我负责申请，这周内给大家结果
孙七：人数最好有个范围，方便准备物资
李四：上次的手套还能用，但垃圾袋需要再买。
王五：预算要不要设个上限，避免超支。
张三：预算控制在 1000 以内，优先用现有物资。
孙七：时间我建议周六上午，天气也不会太热。
李四：九点集合应该比较合适。
赵六：我周三前把申请结果同步到群里。
张三：好，那报名截止时间定在周四晚上。
王五：周五可以统一分组和采购。
孙七：我来负责写报名文案和活动当天的合影安排。
张三：安全方面提醒大家带水，活动结束简单总结一下就行。
张三：那今天就到这，大家按分工推进。
```

## 输出示例

```
- 参会人员：张三、李四、王五、赵六、孙七
- 议题：统一确定下个月社区志愿活动的地点、时间、人数、预算及分工安排。
- 决定：活动定在公园并于周六上午九点举行，按约 50 人规模和 1000 预算执行，由赵六负责场地申请、孙七负责宣传及合影，其余成员配合物资和分组。
```

## 注意事项
- 请确保输入的会议内容清晰完整，包含所有关键发言
- 输出结果会自动整合信息，确保每个要素用一句话表述
- 系统会根据对话内容智能提取和归纳信息，确保总结准确反映会议要点

## 财务提醒
- 仅在提到"钱、预算、采购、费用"时触发
- 须读取"集团财务手册.md"，指出决定中的金额是否超标，并明确审批人

## 上传到服务器
- 当用户提到"上传"、"同步"、"服务器"等关键词时，必须自动执行以下步骤：
  1. 生成会议总结内容
  2. 请打开你的终端工具（Terminal）,运行 upload.py 
  - **脚本使用方法**：
  ```
  C:\ProgramData\Anaconda3\python.exe scripts\upload.py "会议总结内容"
  ```
  3. 运行完后，请把终端返回的原始输出截图或复制给我，证明你真的跑了脚本。”
  4. 创建格式化的HTML文件（文件名为"会议总结.html"）
  5. 保存到项目当前目录下 生成"会议总结.html"
  6. 通知用户文件已创建并提供访问路径

- **HTML文件格式**：使用美观的CSS样式，包含参会人员、议题、决定和财务提醒等内容
- **验证步骤**：每次执行后检查HTML文件是否已成功创建，文件是否保存到了指定位置
